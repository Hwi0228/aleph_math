# ProbOCR

스캔한 문제 이미지를 입력하면 OCR해서 한글 파일, LaTeX, Typst 중 하나로 제공하는 서비스입니다.

## 계정

이메일과 비밀번호로 회원가입/로그인합니다. 비밀번호는 12자 이상이어야 하고 단방향 해시로 저장됩니다. 첫 번째 가입 계정이 관리자가 되며, 기존 문제와 폴더는 첫 계정에 연결됩니다. 이후 가입한 사용자는 자신의 문제와 폴더만 볼 수 있습니다. 관리자는 **계정별 데이터 관리**에서 각 계정의 문제를 조회할 수 있습니다.

운영 배포에서는 세션 서명 키를 `FLASK_SECRET_KEY` 환경 변수로 설정하고, HTTPS를 쓰면 `FLASK_SESSION_COOKIE_SECURE=true`로 지정하세요. 개발 환경에서는 키를 `instance/.secret_key`에 자동 생성하고 Git에서 제외합니다.

## 문제 DB

Flask 앱을 실행한 다음 **문제 DB 등록**을 눌러 과목, 학년, 단원, 지문, 문제 내용, 보기, 선택지, 답, 출처를 입력할 수 있습니다. 수식은 `$...$`, `\(...\)`, `$$...$$`, `\[...\]` 형식으로 작성하며 KaTeX로 미리 보고 렌더링합니다. KaTeX는 jsDelivr CDN에서 불러옵니다.

등록된 문제는 SQLite의 `instance/probocr.sqlite3`에 저장됩니다. 기존 DB를 새 문제 서식으로 자동 마이그레이션하며, 이전에 입력한 문제도 보존합니다. 문제 목록과 문항 수에는 실제 저장된 데이터만 표시합니다. SQLite 파일은 Git에 포함되지 않습니다.

문제 DB 왼쪽의 **＋ 새 폴더**에서 폴더와 하위 폴더를 만들 수 있습니다. 폴더는 UUID로 식별되고 사용자별로 분리됩니다. 문제를 등록할 때 폴더를 지정하거나 문제 카드의 폴더 선택 메뉴에서 기존 문제를 이동할 수 있으며, 폴더를 선택하면 그 아래 하위 폴더의 문제도 함께 조회됩니다. 폴더 이름과 문제 개수는 SQLite에 실제 저장된 내용만 표시합니다.

```powershell
python -m pip install -r requirements.txt
python app.py
```

## 이미지 OCR

로그인 후 사이드바의 **이미지 OCR**에서 문제 이미지 한 장을 올리고 모델을 선택해 문자를 추출할 수 있습니다.

- **TrOCR**: `ddobokki/ko-trocr` 모델에 수평 투영 기반 텍스트 줄 분할과 배치 인식을 적용합니다. 같은 줄의 단어가 간격 때문에 여러 크롭으로 나뉘는 문제를 줄이고, 큰 사진·지도 영역은 줄 검출에서 제외합니다. 스캔 이미지에는 기본으로 Otsu 이진화를 적용하며, OCR 화면에서 끌 수 있습니다. 크롭 좌표와 줄별 인식 결과는 OCR 처리 로그에서 확인할 수 있습니다. 복잡한 2단 편집·도형에서는 읽기 순서가 정확하지 않을 수 있습니다.
- **EasyOCR**: 한국어와 영어를 대상으로 문자 영역을 검출하고 인식합니다.
- **한국어 맞춤법·문장 보정**: `Soyoung97/gec_kr` 한국어 문법 오류 교정 모델을 OCR 후처리에 적용합니다. 오탈자와 띄어쓰기를 함께 보정하도록 시도하며, 수식·기호가 있는 줄은 보정을 건너뜁니다. 선택지 번호는 보정 모델에 넘기지 않고 보존합니다. OCR 화면에서 끌 수 있으며, 모델이 시험 내용이나 고유명사를 잘못 바꿀 수 있으므로 보정 결과는 원문과 대조하세요. 최초 사용 시 약 500MB 모델 다운로드가 필요합니다.
- 선택한 OCR 엔진과 문장 교정 모델은 처음 실행할 때 불러오며, 이후 같은 프로세스에서는 재사용합니다. 모델 가중치 다운로드를 위해 첫 실행 시 인터넷 연결이 필요합니다.
- PNG, JPG/JPEG, WEBP, BMP, TIFF를 지원합니다. 업로드는 최대 12MB, 이미지 해상도는 2,000만 픽셀 이하로 제한됩니다.
- OCR 결과는 검토·복사한 뒤 문제 등록 화면에 붙여 넣을 수 있습니다. 수식, 첨자, 도형, 복잡한 지면 배치는 오인식될 수 있으므로 원본과 대조해야 합니다.

## 의존성 및 실행

OCR용 패키지는 `requirements.txt`에 포함되어 있습니다. 가상 환경에서 다음 명령으로 설치하고 실행하세요.

```powershell
python -m pip install -r requirements.txt
python app.py
```

PyTorch 및 OCR 모델 가중치로 인해 최초 설치·실행 시 다운로드 용량과 로딩 시간이 커질 수 있습니다. CUDA가 지원되는 환경에서는 사용 가능한 GPU를 자동으로 활용하고, 그렇지 않으면 CPU를 사용합니다. 운영 환경에서는 업로드 용량, 메모리, 요청 시간 제한도 함께 설정하세요.
