# Aleph Math

문제를 등록하고 과목·폴더별로 관리하는 웹 앱입니다.

## 계정

이메일과 비밀번호로 회원가입/로그인합니다. 비밀번호는 12자 이상이어야 하고 단방향 해시로 저장됩니다. 첫 번째 가입 계정이 관리자가 되며, 기존 문제와 폴더는 첫 계정에 연결됩니다. 이후 가입한 사용자는 자신의 문제와 폴더만 볼 수 있습니다. 관리자는 **계정별 데이터 관리**에서 각 계정의 문제를 조회할 수 있습니다.

운영 배포에서는 세션 서명 키를 `FLASK_SECRET_KEY` 환경 변수로 설정하고, HTTPS를 쓰면 `FLASK_SESSION_COOKIE_SECURE=true`로 지정하세요. 개발 환경에서는 키를 `instance/.secret_key`에 자동 생성하고 Git에서 제외합니다.

## 문제 DB

Flask 앱을 실행한 다음 **문제 DB 등록**을 눌러 과목, 학년, 단원, 지문, 문제 내용, 보기, 선택지, 답, 출처를 입력할 수 있습니다. 수식은 `$...$`, `\(...\)`, `$$...$$`, `\[...\]` 형식으로 작성하며 KaTeX로 미리 보고 렌더링합니다. KaTeX는 jsDelivr CDN에서 불러옵니다.

등록된 문제는 SQLite의 `instance/probocr.sqlite3`에 저장됩니다. 기존 DB를 새 문제 서식으로 자동 마이그레이션하며, 이전에 입력한 문제도 보존합니다. 문제 목록과 문항 수에는 실제 저장된 데이터만 표시합니다. SQLite 파일은 Git에 포함되지 않습니다.

문제 DB 왼쪽의 **＋ 새 폴더**에서 폴더와 하위 폴더를 만들 수 있습니다. 폴더는 UUID로 식별되고 사용자별로 분리됩니다. 문제를 등록할 때 폴더를 지정하거나 문제 카드의 폴더 선택 메뉴에서 기존 문제를 이동할 수 있으며, 폴더를 선택하면 그 아래 하위 폴더의 문제도 함께 조회됩니다. 폴더 이름과 문제 개수는 SQLite에 실제 저장된 내용만 표시합니다.

## 의존성 및 실행

필요한 패키지는 `requirements.txt`에 포함되어 있습니다. 다음 명령으로 설치하고 실행하세요.

```powershell
python -m pip install -r requirements.txt
python app.py
```
